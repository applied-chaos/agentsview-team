Add Host

Install the agent on a machine to send its sessions to your Instance.

  1. Choose the operating system

    Leave blank to use the machine’s name.

  2. Run this command on the Host

    curl -fsSL https://teams.halcyon.example/install/linux.sh | AVT_TOKEN=avt_tk_9fK2mQx7LwR4tVb8 bash
    curl -fsSL https://teams.halcyon.example/install/macos.sh | AVT_TOKEN=avt_tk_9fK2mQx7LwR4tVb8 bash
    $env:AVT_TOKEN="avt_tk_9fK2mQx7LwR4tVb8"; irm https://teams.halcyon.example/install/windows.ps1 | iex
    This command includes a one-time Install Token valid for 1 hour.

  3. Wait for the Host to connect

    Waiting for the Host to connect…

    It usually takes under a minute.
